# CV - Ansioluettelo

Moderni ja ammattimainen CV-pohja, joka toimii GitHub Pages -sivustona.

## Ominaisuudet

- 📄 Selkeä ja ammattimainen CV-rakenne
- 📱 Responsiivinen design (toimii mobiililaitteilla)
- 🖨️ Print-optimoitu (helppo tulostaa PDF:ksi)
- 🎨 Moderni visuaalinen ilme
- ⚡ Nopea latautuminen

## Sivuston muokkaaminen

Muokkaa `index.html` tiedostoa ja päivitä:
- Nimi ja yhteystiedot
- Profiili/kuvaus
- Työkokemus
- Koulutus
- Osaaminen ja taidot
- Kielet

## Käyttö

1. Muokkaa index.html omilla tiedoillasi
2. Commit ja push muutokset GitHubiin
3. Sivusto päivittyy automaattisesti osoitteeseen: https://dkc76.github.io

## Tulostaminen

Avaa sivusto selaimessa ja käytä selaimen tulostustoimintoa tallentaaksesi CV:n PDF-muodossa.
